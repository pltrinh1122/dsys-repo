# DR-CMD-005: Rename `/meta-eval` → `/eval-meta`; retire `meta-*`

- **Matter:** "`/meta-eval {matter}` vs. `/eval-meta
  {matter}`" — the broad open-text evaluator's name, once
  the specialists move to `eval-*` (DR-CMD-004). Keeping
  `/meta-eval` would leave it the sole `meta-*` member of
  a retired namespace: a proper name with a dead prefix,
  justified only by the weak "family instrument" reading
  (DR-CMD-002, DR-CMD-003 G6).
- **Disposition mode:** ratify. **Proposer:** Peter
  (posed the binary). **Disposer / selector:** Peter
  (ratified, 2026-09-20: "ratify: '/eval-meta',
  '/eval-pb', '/eval-rb'").
- **Framing:** "One stem, three siblings: `eval-*` =
  evaluators, suffix = target, `-meta` = the untyped/open
  case."
- **G5:** binding on the definition file and in-chat
  invocation. Checkable:
  `doc/slash-commands/eval-meta.md` exists; no `meta-*`
  commands remain.

## Options and gate trails

- **O1 — keep `/meta-eval`.** Not selected. Weakened
  (not killed): ratification standing (DR-CMD-002) and
  the operator's earlier want, but the prefix is dead
  once `meta-*` retires.
- **O2 — rename to `/eval-meta`.** G1–G4 pass.
  **Selected.** Completes the vestigial-prefix cleanup;
  every morpheme live in the `eval-*` family; preserves
  both morphemes of the ratified name (continuity).
- **O3 — decide nothing.** Not selected.

## Consequences

- Renamed: `doc/slash-commands/meta-eval.md` →
  `eval-meta.md`.
- **DR-CMD-002's namespace clause is superseded clean:**
  no `meta-*` commands remain (not the stipulated
  "retired namespace + dangling proper name" — the
  retirement is total).
- `-meta` defined: the untyped/open evaluator — matters
  as falsifiable claims, no type declared. The
  falsification posture stands outside the claim,
  including claims *about* validations.
- Updated: `doc/feature-expansion-playbook-spec.md`
  §§A1, 9 references.

## Uncertainties (G6)

- `/eval-claim` is a more descriptive but
  continuity-breaking alternative; not weighed per the
  binary framing.
- Composes with DR-CMD-004; disposed together.
